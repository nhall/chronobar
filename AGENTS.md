# Chronobar

## Contributing

The README and the pages it links are for users. Contributor material is in these files, which those pages don't link to:

- `docs/contributing/development.md`: tests, and the development copy (`--dev`) to run instead of the
  everyday app and its data.
- `docs/contributing/manual-checklist.md`: the hand checks before a release; update it as features
  land.
- `docs/contributing/releasing.md`: tagging and the Homebrew formula.
- `GLOSSARY.md`: the domain terms (Label, Clock time, Pill, Panel, …).
- `docs/adr/`: decisions to respect or explicitly reopen.

## Agent skills

### Issue tracker

GitHub Issues on `nhall/chronobar`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default roles, each label named after its role (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
